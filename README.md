# StarView Analytics (OTT Streaming Content & Subscriber Analytics System)
Run: `python3 seed_data.py` then `python3 server.py`, open http://localhost:8000 (internet needed for fonts and charts).
Streaming-style interface: rotating hero (top titles), stat strip, content rails, title detail pop-ups, revenue, retention/risk and subscriber pages.
Files: schema.sql, seed_data.py, queries.py (all SQL analytics), server.py (REST API), static/index.html (UI), exports/ (CSVs for Excel/Power BI).
Design is inspired by streaming apps; it uses no official logos or artwork.
